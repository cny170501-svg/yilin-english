# 译林英语复习 · 四年级上册（互动复习学习工具）V2.6

面向小学生的译林版（牛津译林）小学英语四年级上册课后复习与课外阅读工具。纯前端响应式网页应用，支持手机竖屏、iPad 横竖屏和电脑浏览器，可添加到主屏幕（PWA）离线使用。

> V2.6 UI 规范化：引入 **Lucide 图标（MIT 开源 SVG 内联，零依赖）** 统一操作类图标（朗读/播放/暂停/停止/提交/翻页/正误反馈/掌握标记，尺寸由按钮类控制，`Util.icon(name, size)`）；补齐设计 token（阴影三阶、focus-visible 焦光环、统一按压反馈）与视觉层级（主按钮渐变阴影、选项对错左色条、反馈横幅色条、进度条渐变加高、导航 active 指示条）。内容性 emoji（单元动物、任务图标）保留儿童亲和力。字号微调：看图默写（中文提示 26→20px、句子提示 21→17.5px、输入框 22→19px、emoji 插图 88→64px）与语法讲解页（标题/例句 16→15px、讲解 14→13.5px、公式 13.5→13px）整体下调。注：shadcn/ui、lucide-react、Motion 为 React 专用，本项目为无框架原生 JS，不适用。
> V2.5 更新：接入 **DaisyUI 4**（Tailwind 组件库）——首页「快捷入口」改用 DaisyUI `card` 组件（`card > card-body + shadow-md`），带悬浮阴影层次；构建时关闭 DaisyUI 主题/base 并用 safelist 白名单（只输出 card/card-body/shadow-md，避免其同名 `.btn` 等组件与手写样式冲突）。
> V2.4 优化：生词复习闭环（生词本 →「生词复习」模式，听写+看中文写混合出题，错题入本）；单元单词列表按掌握状态筛选（全部/未标记/需复习/已掌握，连续播放同步只播筛选结果）；PWA 内容更新提醒。
> V2.3 更新：接入 **Tailwind CSS + @tailwindcss/typography** 排版——双语阅读正文使用 prose 排版层（65ch 舒适阅读栏宽、em 阶梯段距、1.9 行高、品牌色 prose 变量），关闭 preflight 以保证既有界面完全不受影响。
> V2.2 更新：新增「看图默写 · 单词句子听写」专项——看图（emoji 插图）默写单词、看中文写英文、句子默写、听音默写、易错强化五种独立模式；判题忽略大小写与句末标点，逐词定位错误（漏词/多词/复数/拼写），答错自动入错题本并可重练；进度页与家长报告新增默写统计。
> V2.1 更新：新增「语法用法与讲解」专项——11 个主题、28 条规则，每条规则配使用场景、句型公式、可点读例句、正误对比、记忆口诀和即时练习；主题练习含选择/填空/改错/句型转换/连词成句/中译英/情境应用七类题型；语法进度与错题本、首页推荐、进度页、家长报告全部联动。

## 一、快速开始

### 方式 0：在线访问（已部署 GitHub Pages）

手机 / iPad / 电脑浏览器直接打开（无需安装任何东西，支持添加到主屏幕离线使用）：

**https://cny170501-svg.github.io/yilin-english/**

仓库地址：https://github.com/cny170501-svg/yilin-english （更新代码推送到 main 分支后约 1 分钟自动上线）

### 方式 1：双击启动（Windows）

双击 `启动学习工具.bat`，会自动：

1. 启动本地服务器（PowerShell，无需安装任何软件）
2. 打开电脑浏览器访问 `http://localhost:8080`
3. 窗口中会显示本机局域网地址（如 `http://192.168.x.x:8080`），手机/iPad 连同一 WiFi 后用该地址访问

> 若提示"仅本机可访问"，请右键以管理员身份运行一次，或先执行：
> `netsh http add urlacl url=http://+:8080/ user=Everyone`
> 并放行防火墙：`netsh advfirewall firewall add rule name="YilinEnglish Dev 8080" dir=in action=allow protocol=TCP localport=8080`
> 端口被占用时可带参数启动：`启动学习工具.bat 8090`

### 方式 2：任意静态服务器

项目是纯静态文件，把整个 `yilin-english` 目录用任意方式托管即可（python -m http.server / npx http-server / GitHub Pages / 内网 NAS 等）。不建议 file:// 直接打开（PWA 与离线缓存不生效）。

### 手机 / iPad 使用

- 与电脑连同一网络，访问启动窗口显示的局域网地址
- **iPhone/iPad（Safari）**：分享 →「添加到主屏幕」；**安卓（Chrome）**：菜单 →「安装应用」；**电脑**：地址栏安装图标

## 三、内容来源与版权说明（重要）

- **教材部分**：单元标题与单词表依据公开资料整理（同步新版教材词汇表）；例句、句型、知识点、听力材料（16 组情境题 + 8 段小对话）均为本工具围绕教材词汇自编，**不是教材原文或配套录音**。语音由设备自带 TTS 合成。
- **语法专项**：11 个主题围绕教材各单元句型组织（be 动词、单复数与 a/an、Do you like、have/has、can、How many、Where 与介词、would like、How much、his/her、Let's 与祈使句）；讲解、例句、正误对比、口诀与全部练习题为本工具自编。**主题与单元的关联为自编整理（界面标注"待核实"），不是教材官方指定**；语法范围控制在四年级上册所学句型内。
- **看图默写**：「看图」提示为大号 emoji 插图（非教材原图），界面已标注；单词与句子题来自已核实词表与单元句型；「专项强化」含 30 条本工具自编的易错拼写/复数/易混清单（标注为补充练习）；听音使用设备语音合成（非教材录音）。判题为规则比对：忽略大小写与句末标点，逐词定位漏词/多词/复数/拼写错误；**不把拼写或语法错误判为正确**，也不宣称语义评分。
- **阅读文章（8 篇）**：除 2 篇改编自《伊索寓言》（公有领域，原始出处链接到 [Project Gutenberg](https://www.gutenberg.org/ebooks/21)）外，其余 6 篇为本工具原创编写的分级读物；中文翻译由本工具整理。每篇文章页显示具体来源。
- **视频资源（8 条）**：为 YouTube / 官方网站的公开链接导航（Super Simple Songs、Jack Hartmann、Alphablocks、Storyline Online、Peppa Pig、Nat Geo Kids、Oxford Owl、Unite for Literacy）。**本工具未抓取、未翻译任何视频字幕**；"学习重点"为人工整理的复习提示。访问 YouTube 需相应网络环境。
- 所有内容可在「设置 → 内容管理」导出、修改、带校验导入（阅读与听力内容暂为内置数据文件，暂不支持界面导入，见 roadmap）。

## 四、数据保存说明

- 学习进度、错题本、阅读记录、生词本、每日任务保存在**当前设备浏览器**（localStorage），刷新/重开不丢失；**换设备不同步**（未接入云端），可在设置中导出 JSON 备份。
- V1 升级到 V2 **不丢数据**：旧记录（单词掌握、单元统计、错题、连续天数、设置）完整保留，新统计字段自动补默认值（已实测验证）。
- 开发者注意：修改 `js/`、`css/`、`data/` 下任何文件后，请把 `sw.js` 里的 `CACHE` 版本号 +1，否则已安装的 PWA 会继续使用旧缓存。

### Tailwind Typography 构建说明

阅读正文排版由 `@tailwindcss/typography` 编译生成（`css/tw-typography.css`），运行时零依赖。修改排版后重新构建：

```powershell
cd yilin-english\tw
..\tools\node20\npm.cmd install   # 首次
..\tools\node20\npm.cmd run build # 生成 ../css/tw-typography.css
```

要点：`tailwind.config.js` 中 `corePlugins.preflight` 已关闭（避免样式重置破坏手写界面）；DaisyUI 关闭 `themes`/`base` 且 `content` 只扫 index.html、组件类走 `safelist` 白名单（防止 DaisyUI 的 `.btn` 等同名组件污染手写样式）；`css/tw-typography.css` 必须在 `style.css` **之前**引入；prose 品牌色等变量在 `style.css` 的「协调层」中调整。

## 六、内容 JSON 格式（教材导入）

```json
{
  "title": "教材名称",
  "sourceNote": "内容来源说明",
  "units": [{
    "id": "u1", "no": 1, "title": "I like dogs", "titleZh": "我喜欢狗", "emoji": "🐶",
    "words": [{ "en": "dog", "zh": "狗", "exEn": "I like dogs.", "exZh": "我喜欢狗。" }],
    "sentences": [{ "en": "Do you like dogs?", "zh": "你喜欢狗吗？" }],
    "grammar": [{ "title": "…", "explain": ["…"], "examples": [{"en":"…","zh":"…"}],
      "quiz": [{ "q": "…", "options": ["A","B","C","D"], "answer": 1, "explain": "…" }] }]
  }]
}
```

最小要求 `units[].{id,title,words[].{en,zh}}`，其余可选。阅读/听力内容如需自定义，参照 `data/reading.js`、`data/listening.js` 的结构直接编辑文件。

## 七、常见问题

- **听力/点读没声音**：iOS 检查静音键；首次点击任意按钮激活语音；设置里可试听。语速可在设置或阅读页快速调节。
- **听写/翻译总判错**：判分忽略大小写与标点；单词需拼写完全一致；长句允许少量差异（词重合 ≥80% 判基本正确），判分规则见练习页说明——不是智能语义评分。
- **手机打不开局域网地址**：同一 WiFi、防火墙放行（见快速开始）、或以管理员重启动脚本。
- **改了代码/内容不生效**：升 `sw.js` 的 CACHE 版本号后刷新。
- **视频打不开**：YouTube 资源需相应网络环境；也可使用 Storyline Online / Oxford Owl / Unite for Literacy 等网站类资源。
